# Guidance for coding agents

## Repository content

- Describe this project as independent engineering work: the problem, the design
  decisions, the experiments, and the results.
- Never include the owner's job-search strategy, target employers, job applications, or
  personal career plans in tracked files, commit messages, PR titles, or PR
  descriptions without the owner's explicit approval. Explain decisions with technical
  requirements, not with who the work is for.
- Company or product names may appear only as clearly labelled technical references
  (a cited paper, benchmark, dataset, or library) or as conceptual examples, never as a
  target audience.
